# Modelos face-api.js

Incluye los modelos preentrenados compatibles de face-api.js descargados del directorio oficial `weights/` del repositorio `justadudewhohacks/face-api.js` en GitHub. Están aquí los manifests y shards para `tiny_face_detector`, `face_landmark_68` y `face_recognition`.

Los pesos no hacen PAD: no detectan de manera confiable fotos impresas, pantallas ni videos. Revisa los términos aplicables a los pesos/modelos antes de cualquier uso real. La aplicación no permite autorización automática; el enrolamiento completo sigue pendiente.
